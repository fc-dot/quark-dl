> **禁止用本工具下载后再对外分发/传播资源**。详见 [LICENSE](LICENSE)。

把夸克网盘**分享链接**里的文件下载到本地。支持断点续传、只下载其中一部分文件、512 连接并发。

> 完整说明见 [使用说明.md](使用说明.md)

---

## 功能

- 输入分享链接，自动转存 + 下载，保留目录结构
- 支持只下载某个文件 / 某个目录（`--only`）
- `--list` 只看清单，不转存、不下载
- 断点续传：中断后重跑同一条命令继续
- 自动识别链接里的提取码（`?pwd=`）
- 512 连接并发，实测约 5 MB/s（非会员账号）

---

## 快速开始

1. 安装 Python 3.9+
2. 双击 `安装依赖.bat`（安装 `curl_cffi`）
3. 双击 `夸克下载.bat`，按提示粘贴分享链接

第一次运行会让你粘贴一次浏览器 Cookie，详见 [使用说明.md](使用说明.md) 第六节。

### 命令行

```powershell
python src\quark.py "https://pan.quark.cn/s/xxxxx"
python src\quark.py "https://pan.quark.cn/s/xxxxx" --list
python src\quark.py "https://pan.quark.cn/s/xxxxx" --only "顶层目录/子目录/文件名.zip"
```

| 参数 | 作用 |
|---|---|
| `--list` / `--dry-run` | 只列出文件，不下载 |
| `--only "路径"` | 只下载该文件；以 `/` 结尾表示整个目录 |
| `-o "目录"` | 保存到指定目录 |
| `--passcode 1234` | 提取码（链接带 `?pwd=` 时自动识别） |
| `-t 128` | 连接数，默认 512（实测最快） |

## 实现要点

- **TLS 指纹**：夸克按 TLS 指纹拦截非浏览器客户端（表现为握手后立刻断开），本项目用
  `curl_cffi` 的 Chrome 指纹，并在多套指纹间自动轮换
- **大文件限制**：网页端取链会返回 `23018 download file size limit`，换用 PC 客户端 UA 才能取到
- **直链必须带 Cookie**：否则 CDN 返回 `412 Precondition Failed`
- **多连接叠加**：实测 512 连接最快，1024 反而因连接建不全而变慢
